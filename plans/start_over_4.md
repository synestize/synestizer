#### **Phase 4: Hook Integration and UI Activation**

**Action 4.1: Integrate the `useWebcam` Hook into the Main App**

Modify `src/App.tsx`. We will call the hook here to manage the webcam lifecycle at the top level of the application.

```typescript
// src/App.tsx

import { Header } from './components/Header';
import { VideoFeed } from './components/VideoFeed';
import { Controls } from './components/Controls';
import { useWebcam } from './hooks/useWebcam';
import { useAppStore } from './store/useAppStore';
import { useEffect } from 'react';

function App() {
  const { videoRef, canvasRef, error, startWebcam, stopWebcam } = useWebcam();
  const { isAudioRunning } = useAppStore();

  useEffect(() => {
    // This effect synchronizes the webcam with the global audio state
    if (isAudioRunning) {
      startWebcam();
    } else {
      stopWebcam();
    }
  }, [isAudioRunning, startWebcam, stopWebcam]);

  return (
    <div className="bg-gray-800 text-white min-h-screen flex flex-col">
      <Header />
      <main className="flex-grow flex flex-col items-center justify-center p-4">
        <VideoFeed videoRef={videoRef} />
        <Controls />
        {error && <div className="mt-4 p-2 bg-red-800 text-white rounded">{error}</div>}
      </main>
      {/* The canvas is required for processing but should not be visible to the user */}
      <canvas ref={canvasRef} style={{ display: 'none' }} />
    </div>
  );
}

export default App;
```

**Action 4.2: Update the `VideoFeed` Component to Use the `videoRef`**

Modify `src/components/VideoFeed.tsx` to accept the `videoRef` from its parent and attach it to the `<video>` element.

```typescript
// src/components/VideoFeed.tsx

import { RefObject } from 'react';

interface VideoFeedProps {
  videoRef: RefObject<HTMLVideoElement>;
}

export function VideoFeed({ videoRef }: VideoFeedProps) {
  return (
    <div className="bg-black aspect-video w-full max-w-4xl rounded-lg shadow-lg overflow-hidden">
      <video
        ref={videoRef}
        className="w-full h-full object-cover"
        autoPlay
        playsInline
        muted
      />
      {/* The video element is muted by default to prevent audio feedback. Sound is generated by Tone.js. */}
    </div>
  );
}
```

**Action 4.3: Clean up the `Controls` Component (No changes needed)**

Reviewing the plan, the existing `Controls.tsx` and `useAppStore.ts` already do exactly what we need. The `Controls` component triggers `startAudio`/`stopAudio` in the store. The new `useEffect` hook we added in `App.tsx` now listens for that state change and calls `startWebcam`/`stopWebcam` accordingly. The orchestration is complete and correctly decoupled.

### Testing and Validation Plan

After the AI assistant completes the actions above, perform the following manual tests to validate that the MVP is fully functional.

**Test Case 1: Initial State**
1.  Run the application (`pnpm dev`).
2.  Open the app in your browser.
3.  **Expected Result:** The UI displays the "Synestizer Indigo" header, a black box for the video feed, and a green "Start" button. The webcam light on your computer should be **off**.

**Test Case 2: Successful Start and Operation**
1.  Click the "Start" button.
2.  The browser will likely ask for permission to use your camera. **Click "Allow"**.
3.  **Expected Result:**
    *   The "Start" button immediately changes to a red "Stop" button.
    *   Your webcam video stream appears in the video feed area. The webcam light on your computer turns **on**.
    *   You should hear a continuous synthesized sound.
    *   Move your hand over your webcam, making the view darker and brighter. You should hear the **pitch of the sound change** in response. This confirms the entire pipeline (Video -> Canvas -> Worker -> AudioService) is working.

**Test Case 3: Successful Stop**
1.  While the application is running, click the "Stop" button.
2.  **Expected Result:**
    *   The video feed stops, likely showing the last frame or turning black.
    *   The webcam light on your computer turns **off**.
    *   The sound stops completely.
    *   The button reverts to the green "Start" button.

**Test Case 4: Error Handling (Webcam Permission Denied)**
1.  Stop the application if it is running. You may need to reset camera permissions in your browser's site settings for this test.
2.  Reload the page and click "Start".
3.  When the browser asks for permission, **click "Block" or "Deny"**.
4.  **Expected Result:**
    *   An error message ("Failed to access webcam. Please check permissions.") should appear below the controls.
    *   The video feed should remain black.
    *   No sound should play.
    *   The button should revert to "Start". The application should remain stable and not crash.
